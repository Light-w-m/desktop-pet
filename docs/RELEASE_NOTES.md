茜特菈莉桌宠 · 表情九宫格与完整动画

- 完整保留人物、整个抱枕和动作道具，包含站立、喝饮料、读书三组动画。
- 保留原生 60 FPS 帧与无损画质，动作自然结束后衔接下一组。
- 修复站立脚底倒影闪动和背后两条飘带的透明轮廓。
- 迷你粉色右键菜单，主菜单与表情面板宽高约缩小一半，弹窗显示在人物旁边，靠近屏幕边缘时自动换边，切换动作后继续避开人物。
- 右键选择“表情”展示九宫格；内置 9 款透明表情，点击后显示在桌宠右上角，5 秒后自动消失，再次选择重新计时。表情随拖动、缩放和动作调整位置，也可在面板手动清除。
- 表情不拦截鼠标，缩略图按需在后台解码，缓存数量受限。
- 主菜单的“表情”和“语音”并排显示，去掉表情数量；语音列表仅包含保留的条目，支持点选播放、停止、分页和滚轮翻页，同一时间播放一条。
- 改为按需读取和有限帧缓存，默认尺寸本机回归工作集峰值约 45 MiB，大号约 72 MiB。

下载说明：

- 普通使用：下载 `CitlaliDesktopPet.exe`，在 Windows x64 双击运行，不需要 Python。程序内置动画、表情和保留的语音素材。
- 源码开发：额外下载 `CitlaliDesktopPet-source-assets.zip`，解压到源码根目录，再按 README 构建。
- `SHA256SUMS.txt` 提供两个下载文件的 SHA-256 校验值。
