茜特菈莉桌宠 · 表情九宫格与完整动画

- 完整保留人物、整个抱枕和动作道具，包含站立、喝饮料、读书三组动画。
- 保留原生 60 FPS 帧与无损画质，动作自然结束后衔接下一组。
- 修复站立脚底倒影闪动和背后两条飘带的透明轮廓。
- 新增柔和粉色右键菜单，支持动作选择、自动轮换、暂停和大小调整。
- 右键选择“表情”展示九宫格；内置 9 款透明表情，点击后显示在桌宠右上角，随拖动、缩放和动作调整位置，可在面板清除。
- 表情不拦截鼠标，缩略图按需在后台解码，缓存数量受限。
- 改为按需读取和有限帧缓存，默认尺寸本机回归工作集峰值约 45 MiB，大号约 72 MiB。

下载说明：

- 普通使用：下载 `CitlaliDesktopPet.exe`，在 Windows x64 双击运行，不需要 Python。程序内置动画和表情素材，EXE 约 585 MiB。
- 源码开发：额外下载 `CitlaliDesktopPet-source-assets.zip`，解压到源码根目录，再按 README 构建。
- `SHA256SUMS.txt` 提供两个下载文件的 SHA-256 校验值。
