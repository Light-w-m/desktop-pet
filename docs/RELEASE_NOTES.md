茜特菈莉桌宠 v1.2.0 · 拖动互动与中文语音

- 完整保留人物、整个抱枕和动作道具，包含站立、喝饮料、读书三组动画。
- 保留原生 60 FPS 帧与无损画质，动作自然结束后衔接下一组。
- 修复站立脚底倒影闪动和背后两条飘带的透明轮廓。
- 迷你粉色右键菜单，主菜单与表情面板宽高约缩小一半，弹窗显示在人物旁边，靠近屏幕边缘时自动换边，切换动作后继续避开人物。
- 右键选择“表情”展示九宫格；内置 9 款透明表情，点击后显示在桌宠右上角，5 秒后自动消失，再次选择重新计时。表情随拖动、缩放和动作调整位置，也可在面板手动清除。
- 表情不拦截鼠标，缩略图按需在后台解码，缓存数量受限。
- 左键双击随机显示“有点烦”或“脸红”，开始拖动时随机显示“不想面对”或“来了”；每次拖动触发一次，互动表情同样在 5 秒后自动消失。
- 拖动时播放提供的局部抱枕 GIF 动作：透明抠图、运动补偿至 60 FPS、循环衔接和开始/松手的短渐变；松手后继续此前动作。README 顶部加入提供的封面图。
- 主菜单的“表情”和“语音”并排显示，去掉表情数量；语音列表包含保留的 29 条中文语音，支持点选播放、停止、分页和滚轮翻页，同一时间播放一条。
- 喝饮料每轮开始后延迟 0.5 秒配对播放“闲聊·喝酒”；站立时隔 45～90 秒随机播放“闲聊·小说”或“闲聊·出神”，不打断手动点播。
- 语音面板增加开关与每次 10% 的音量加减，保持弹窗原尺寸。支持即时静音、当前语音音量调整和本地保存；只调节桌宠自身音量。
- 音量加减号和翻页箭头放大并居中，采用清晰的圆润线条。
- 保持按需读取和受限帧缓存，主动作与拖动动画实机约 60 FPS；默认尺寸的进程组工作集峰值约 47 MiB。修复重复选择相同大小时可能卡住的缓存问题。

下载说明：

- 普通使用：下载 `CitlaliDesktopPet.exe`，在 Windows x64 双击运行，不需要 Python。程序内置动画、表情和保留的语音素材。
- 源码开发：额外下载同版本的 `CitlaliDesktopPet-source-assets.zip`，解压到源码根目录，包含主动画、拖动帧包和语音素材，再按 README 构建。
- `SHA256SUMS.txt` 提供两个下载文件的 SHA-256 校验值。
