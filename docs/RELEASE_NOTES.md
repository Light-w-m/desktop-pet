茜特菈莉桌宠 v1.3.0 · 跺脚彩蛋、待机语音与体积优化

- 新增晃动彩蛋：按住人物明显来回晃动，停下或松手后跺一次脚，同时显示专属生气表情；表情 5 秒后消失，不占原有九宫格。
- 跺脚使用新视频，去掉双手前伸的开头，只保留约 1.3 秒的抬脚、落脚和收势。按站立素材统一亮度与色调，结束后平滑回到正常站立，三档尺寸实测约 59～60 FPS。
- 跺脚随机配对三条“元素爆发”和两条“重受击”中文语音，避免连续重复；支持原有语音开关、音量和手动点播优先级。
- 自由切换按“站立 → 喝饮料 → 站立 → 读书”轮换，两段站立各约 30 秒，进入站立后 8～12 秒随机播放一次“闲聊·小说”或“闲聊·出神”。手动单独站立仍保持 45～90 秒闲聊间隔。
- 修复语音末尾播放不完整：保留完整原声与 0.25 秒静音缓冲，等设备播放完成后释放声道；手动停止、静音和切换语音仍可立即生效。本版内置 34 条保留的中文语音。
- EXE 约 229 MiB。五种动画共 2178 帧，采用无损原生帧包和受限缓存；短跺脚帧独立编码，减少动作切换时的读取等待。压缩前后逐帧像素与透明度一致。
- 保留完整人物、抱枕、拖动动画、迷你粉色菜单、9 款常规表情、双击互动以及脚底倒影和飘带轮廓修复。
