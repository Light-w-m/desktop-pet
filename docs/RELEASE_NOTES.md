下载说明：

- 普通使用：下载 `CitlaliDesktopPet.exe`，在 Windows x64 双击运行，不需要 Python。程序内置动画、表情和保留的语音素材。
- 源码开发：额外下载同版本的 `CitlaliDesktopPet-source-assets.zip`，解压到源码根目录，包含主动画、拖动帧包和语音素材，再按 README 构建。
