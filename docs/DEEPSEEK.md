# 桌宠对话与图片识别

右键人物 → **和她聊天**，或人物获得焦点后按 **Enter**，在人物右侧打开独立对话框。在输入框打字后按 Enter 或点击“发送”；Shift+Enter 换行。点击对话框以外的窗口或桌面即可收起，也可以按 Esc 或点击右上角 ×。收起后仍保留本次会话、未发送的草稿和已选图片；重新打开可以继续。选图对话框属于聊天窗口，打开它不会触发收起。屏幕右侧空间不足时自动切到左侧，保持面板可见并避开人物。请求在后台完成，动画继续播放。

聊天记录采用左右分开的圆角气泡：你的消息靠右，使用浅粉色底；桌宠回复靠左，使用白色底。不再在每条消息前显示“你”或“茜特菈莉”。长消息自动换行，保留输入的换行；可以滚动查看、选中文字并复制。滚动到前面阅读时，新回复保留当前阅读位置；发送新消息时自动回到最新位置。错误提示使用居中的浅灰色气泡。

## 图片识别

点击底部 **图片**，手动选择一张 PNG、JPG、WebP 或 GIF。输入框下方显示缩略图和文件名，点旁边的 × 可以移除；只有点击“发送”才会提交给 DeepSeek。可以附带问题，也可以只发图片，让桌宠描述图片。发送后图片显示在右侧消息气泡里，回复仍然是文字。

单张原始图片最多 20 MB、4000 万像素，提交前会保持比例缩小到最长边 2048 像素，并转换为最多 2 MB 的 PNG 或 JPEG，去除 EXIF、GPS 等元数据；动图只识别第一帧。图片仅保留在当前程序内存中，不生成上传副本、图片日志或聊天文件。为便于追问，每次请求最多附带当前会话最近两张图片。图片也会计入 API 用量。

不自动截图、不扫描目录、不获取其他窗口或剪贴板内容；文件选择器只读取用户明确选中的图片。图片中的文字作为待分析内容，不作为电脑操作指令。

## 能力限制

桌宠直接调用 DeepSeek 官方 HTTPS 对话接口，不启动或连接 CLI、浏览器、本地智能体服务。模型固定为 `deepseek-flash`，使用同一个 API Key，关闭思考，每条输入最多 2000 字，每次输出最多 1024 tokens。

请求固定传入空工具列表和 `tool_choice: none`。模型没有命令执行器、文件操作工具、浏览器工具、鼠标键盘控制工具、插件或 MCP；客户端唯一增加的文件读取是用户手动选图。即使服务意外返回工具调用或旧式 function call，客户端也会拒绝该回答，不执行操作。回答显示在原生只读文本框中，代码和链接也是普通文字，不会运行或打开。

只把用户主动输入的消息、手动选取并发送的图片、最近最多 8 组问答和固定聊天提示词发给 API。不会发送其他文件、目录内容、运行程序列表或电脑信息。消息仅保存在内存，“清空”删除当前对话和待发送图片，退出桌宠后不保留；关闭并重新打开面板可以继续当前会话。API 仍按实际 token 用量计费。

## API Key

点击面板右上角 **设置**，输入 DeepSeek API Key 并保存。已保存的密钥不会回填到输入框；留空保存会继续使用原密钥。无 Key、Key 无效、余额不足或网络超时会在界面中提示。

设置默认保存在 `D:\AI\DeepSeek\data\pet-chat.json`，使用 Windows DPAPI 加密，绑定当前 Windows 账号。密钥不写入源码、EXE、聊天内容或日志。也支持启动环境中的 `DEEPSEEK_API_KEY`，优先使用加密设置。已有的本机 DeepSeek Key 已迁移到这个独立的聊天配置。

本机的旧 Harness 服务已停止，桌宠不再启动或连接它。旧的 `--deepseek` 启动参数也只打开原生文字聊天面板。独立聊天入口是 `CitlaliDesktopPet.exe --chat`，`D:\AI\DeepSeek\Open Chat.cmd` 和原有的 `Open DeepSeek.cmd` 均指向该入口。再次打开入口会唤起当前桌宠的面板，不会再启动一只桌宠。

如需在其他位置保存设置，可以在启动前设置 `CITLALI_DEEPSEEK_ROOT`。源码准备脚本为 `python work/prepare_chat.py`；它只创建本机配置目录和快捷启动文件，不安装 CLI 或智能体。

## 验证

- `work/test_deepseek.py`：空工具请求、固定模型及输出上限、输入和上下文限制、工具调用拦截、纯文本响应、密钥加密与注入字符拦截。
- `work/test_chat_ui.py`：左右气泡与不同底色、无发送者前缀、长文本换行、滚轮和滚动条、阅读位置保留、文字选择、原生输入与回答、异步请求时动画继续、跟随人物、清空、关闭后重开、密钥输入框不暴露已保存的 Key。
- `work/test_chat_features.py`：删除提示文字、选图预览与移除、发送前不上传、图片气泡、内部点击、外部激活收起、选图弹窗豁免及草稿保留。
- `work/verify_text_chat.py`：真实 API 问答、图片内容识别和操作请求的文字拒绝、原生面板截图及验证记录。
- `work/verify_packaged_chat.py`：在实际 EXE 中输入问题，验证原生窗口、加密密钥读取及真实 API 回答。

[DeepSeek Chat Completion 参数说明](https://api-docs.deepseek.com/api/create-chat-completion/) 中的 `tool_choice: none` 表示模型不调用工具。客户端同时没有任何接收并执行模型动作的代码路径。

[DeepSeek 图片输入说明](https://api-docs.deepseek.com/guides/vision/) 说明 `deepseek-flash` 可直接接收图片，本客户端使用内嵌图片数据的方式提交选中的图片。
